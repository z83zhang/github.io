## Selected Work

### Metric Intelligence Agent

An agentic tool that answers data questions for product managers and data scientists in plain English, without requiring SQL.

At companies with mature data foundations, top-line metrics live in dashboards — but PMs and data scientists constantly need more: derived metric questions that require knowing the schema, canonical definitions, and which tables to trust. This tool answers them automatically — with a reflection loop that checks its own work before returning a trusted result.

**Built with:** Python · DuckDB · OpenAI · LangGraph · pandas · Streamlit

[View the project](https://github.com/z83zhang/ai-data-engineering/tree/main/metric_intelligence_agent)

### Multimodal Search Pipeline

A search pipeline for meeting audio and slides. It transcribes speech, extracts text from slides, and indexes both so users can find relevant information across a meeting. The repo includes transcription and retrieval evaluations using WER and Precision@5.

**Built with:** Python · Whisper · Tesseract · ChromaDB

[View the project](https://github.com/z83zhang/ai-data-engineering/tree/main/multimodal-search-pipeline)

## About

I design and build data foundations that help organizations understand their products and act on what they learn. At Meta, I have led the design of data architecture for consumer products, from defining logging and metrics to building scalable data models and pipelines. I work closely with product, engineering, and data science teams to identify opportunities to improve the user experience.

My earlier work in finance includes J.P. Morgan and Parallax Volatility Advisers, where I worked on data and analytics for financial and trading workflows. Across these settings, I have seen recurring problems between the teams that build data systems and the people who depend on them. I am interested in using AI to rethink the data layer itself — building stronger data foundations, automating traditionally manual data workflows, and making trusted data access and analysis more self-serve. I build and test tools that explore how AI can help teams understand, maintain, and operate complex data systems, while giving more people direct access to reliable data and faster paths from questions to decisions.
